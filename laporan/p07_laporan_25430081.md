2. Ringkasan Dasar Teori
DQL (Data Query Language) melalui perintah SELECT merupakan komponen SQL yang berfungsi untuk mengambil dan menampilkan data dari tabel basis data. Untuk memanipulasi serta mentransformasi tampilan nilai data pada baris individual, SQL menyediakan Fungsi Skalar (Scalar Functions).

Pada lingkungan basis data relasional, penerapannya meliputi aspek-aspek utama berikut:
- Fungsi String: Digunakan untuk mentransformasi teks, seperti mengubah format huruf (UPPER(), LOWER()), menghitung panjang karakter (LENGTH()), dan menggabungkan beberapa kolom teks (CONCAT()).
- Fungsi Penanganan Nilai Kosong (IFNULL): Mengganti nilai NULL pada kolom dengan nilai pengganti (default) agar tampilan data lebih informatif.
- Ekspresi Kondisi (CASE WHEN): Memberikan logika percabangan di dalam perintah SELECT untuk mengkategorikan data secara dinamis berdasarkan kriteria tertentu.
- Fungsi Tanggal & Waktu (NOW(), CURDATE()): Mengambil stempel waktu terkini dari server DBMS untuk kebutuhan pencatatan log transaksi atau pelaporan.

4. Jawaban Titik Analisis

- Titik Analisis 1: Mengapa kueri WHERE nama_mahasiswa LIKE '%Aha%' sebelumnya menghasilkan Empty set?
  Jawab: Karena klausa LIKE bersifat spesifik terhadap karakter yang dicari. Data nama pada tabel tersimpan dengan kata "Adha" (huruf 'd'), sedangkan kueri mencari huruf 'h' ("Aha"), sehingga server tidak menemukan baris yang cocok.

- Titik Analisis 2: Apa fungsi penggunaan tanda kurung siku/petik atau underscore pada penamaan folder saat eksekusi perintah SOURCE?
  Jawab: Perintah SOURCE pada konsol MariaDB peka terhadap karakter spasi pada jalur (path) file. Penggunaan underscore (basis_data_25430081) mencegah terjadinya error: 13 (Permission Denied) atau error: 2 (File Not Found).

- Titik Analisis 3: Mengapa Kebutuhan Informasi tertentu (seperti KI-11 dan KI-12) belum dapat dijawab dengan kueri 1 tabel?
  Jawab: Karena informasi yang dibutuhkan (seperti nama dosen pengampu mata kuliah atau total SKS mahasiswa) terpisah di beberapa tabel (mata_kuliah, kelas, krs), sehingga memerlukan teknik penggabungan relasi (JOIN) dan fungsi agregat (SUM, GROUP BY) yang dipelajari pada modul berikutnya.
