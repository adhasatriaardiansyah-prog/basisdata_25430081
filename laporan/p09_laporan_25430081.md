2. Ringkasan Dasar Teori
Pada tahap pengolahan laporan eksekutif dan ringkasan data akademis (Milestone Proyek Modul 9), beberapa konsep utama yang diterapkan meliputi:
- Aggregate Functions: Fungsi SQL seperti COUNT(), SUM(), AVG(), MIN(), dan MAX() yang memproses sekumpulan nilai baris data untuk menghasilkan satu nilai ringkasan ringkas.
- Grouping & Filtering (GROUP BY & HAVING): Klausa GROUP BY membagi baris tabel menjadi kelompok-kelompok berdasarkan nilai kolom tertentu. Klausa HAVING digunakan khusus untuk menyaring hasil pengelompokan berdasarkan kondisi agregat, berbeda dengan WHERE yang menyaring baris sebelum dikelompokkan.
- Hierarchical Summarization (WITH ROLLUP): Ekstensi klausa GROUP BY yang menghasilkan baris agregat tambahan berupa subtotal dan grand total. Baris tingkat atas ini ditandai dengan nilai NULL pada kolom grup.
- Strict Aggregation Mode (ONLY_FULL_GROUP_BY): Aturan pengujian SQL mode di MariaDB/MySQL yang mewajibkan semua kolom non-agregat di klausa SELECT untuk dicantumkan secara eksplisit pada klausa GROUP BY guna menjamin kepastian deterministik hasil kueri.

4. Jawaban Titik Analisis

- Titik Analisis 1: Mengapa pengaktifan mode ONLY_FULL_GROUP_BY menyebabkan Error 1055 jika ada kolom non-agregat di SELECT yang tidak masuk di GROUP BY?
  Jawab: Karena mode ONLY_FULL_GROUP_BY melarang server MariaDB memilih nilai secara acak/tidak deterministik dari baris-baris dalam satu kelompok. Menuliskan seluruh kolom non-agregat di klausa GROUP BY menjamin bahwa setiap kelompok baris memiliki pasangan nilai yang pasti dan konsisten secara semantik.

- Titik Analisis 2: Apa perbedaan mendasar antara COUNT(*) dan COUNT(DISTINCT nama_kolom) saat digunakan bersama klausa JOIN?
  Jawab: COUNT(*) menghitung seluruh jumlah baris hasil gabungan tabel (termasuk duplikasi akibat relasi one-to-many), sedangkan COUNT(DISTINCT nama_kolom) hanya menghitung jumlah nilai unik yang tidak berulang dan mengabaikan nilai NULL.

- Titik Analisis 3: Kapan syarat penyaringan data harus dituliskan di klausa WHERE dan kapan harus di klausa HAVING?
  Jawab: Syarat penyaringan diletakkan di WHERE jika penyaringan dilakukan pada baris data dasar sebelum proses pengelompokan (misal: WHERE status_aktif_mahasiswa = 'Aktif'). Syarat diletakkan di HAVING jika penyaringan bergantung pada hasil perhitungan fungsi agregat (misal: HAVING COUNT(m.id_mhs) > 5).
